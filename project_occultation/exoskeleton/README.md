# Project Occultation · exoskeleton
## Introduction
Exoskeleton is a Qt based thin shim that provides minimal set of KWin function that is used by Project Occultation.

Remember Project Occultation aims to re-use `gxde-kwin`'s interface? Exoskeleton provides a minimal backend for QML frontend to use.
