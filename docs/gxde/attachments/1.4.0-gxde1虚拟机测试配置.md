## 在VM上开启远程登录
```bash
$ sudo apt update
$ sudo apt install openssh-server -y
$ sudo systemctl enable --now ssh
```

## 现有软件包更新
### Deepin Daemon
Deepin Daemon的`dock`模块会强行建立X连接，在Wayland上会导致整个Daemon闪退，导致会话一直在等待daemon从而卡在黑屏。

需要更新到`4.0.9-1`:
```bash
$ sudo apt install dde-daemon dde-dconfig-daemon
```

### GXDE Terminal
修复终端双标题栏与菜单问题
```bash
sudo apt install gxde-terminal
```

## 软件包安装
>  **注意**: 在使用`./build-deb`时，构建`.deb`包会使用全部线程，这可能会造成编译期间系统卡顿。
{.is-warning}

### GXDE Wlcom
即本仓库，使用`./build-deb`构建。

### 文件管理器/桌面
在实体机上克隆仓库：
```bash
$ git clone git@gitee.com:MarcusP/gxde-file-manager.git
```

进入仓库，编译打包：
```bash
$ chmod a+x ./build-deb
$ ./build-deb -d
```
`-d`参数会自动使用`apt`安装所需的devel包，若脚本运行中无报错则代表`.deb`包构建成功，产物可以在仓库的上级目录被找到。

通过`scp`将构建产物拷贝至VM并安装: 
```bash
# 本机
$ scp <本机DEB的位置> <VM用户名>@<VM IP地址>:/tmp/<DEB名>
$ ssh <VM的IP>

# VM上
$ sudo apt install /tmp/<DEB名>
```
请确保把构建的几个`.deb`包全部安装了。
